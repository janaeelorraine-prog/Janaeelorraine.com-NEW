# Site background images

The site theme references two painting backgrounds. **The two `.jpg` files here are
temporary placeholders** (flat warm gradients) so pages render without 404s. Replace
them with the real paintings, keeping the **exact same filenames**:

| Filename | Painting | Used on (hero background) |
|----------|----------|---------------------------|
| `drum-circle.jpg` | Dancer + drummers (warm barn ritual scene) | booking, shop, certification, initiation |
| `ancestral-tree.jpg` | Tree-of-faces + meditation | index (home), courses, library, courses-portal, portal |

To replace: commit new files to `images/drum-circle.jpg` and `images/ancestral-tree.jpg`
(same names, overwrite). No CSS changes needed — the theme picks them up automatically.

Recommended: portrait-ish JPGs ~1200px+ on the long edge, optimized (< ~400 KB each)
for fast load. Each is layered under a dark overlay in the hero, so mid-tone,
detailed art reads best.
